# ESTUDIO VOICE DJ

Primeira versão da plataforma de criação de locuções profissionais.

## Estrutura

- `index.html` — tela principal
- `style.css` — visual e responsividade
- `script.js` — interações da interface

## Como testar

Abra o arquivo `index.html` no navegador.
